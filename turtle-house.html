My Turtle House

Write Python instructions to tell the turtle exactly how to build a house. Then run your program and see what happens.

YOUR PROGRAM

import turtle t = turtle.Turtle() t.speed(5) # House t.fillcolor("lightblue") t.begin_fill() for i in range(4): t.forward(150) t.left(90) t.end_fill() # Roof t.fillcolor("red") t.begin_fill() t.left(45) t.forward(106) t.left(90) t.forward(106) t.left(45) t.end_fill() # Door t.penup() t.goto(55, 0) t.pendown() t.fillcolor("brown") t.begin_fill() t.left(90) t.forward(80) t.right(90) t.forward(40) t.right(90) t.forward(80) t.end_fill() turtle.done()

In this project, I used Python Turtle commands to control a turtle. I learned how commands such as forward(), left(), penup(), and goto() can work together to create a drawing.
